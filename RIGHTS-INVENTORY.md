## What was deliberately not taken

- Nothing else from the emma web repository ("Memora3"). That repository has
  no `LICENSE` file and no `license` field in its `package.json`. Only the two
  files named above, whose authorship is recorded in the repository's own
  history, were used as sources, and only by reading them. The viewer links
  to no code from there.
- No emma product text beyond the fixed sentences the readers already record
  ("Written in Emma", "Not recorded", "Consent not established by the legacy
  file.", "Local memory backup; importing grants no agent access.") and the
  one-line legacy warning restated in plain words. These are needed to show a
  file as the app would.
- No private vault, passphrase, code word, fingerprint, vault ID, name, photo
  or recording. Every vector is generated by `tools/make-fixtures.mjs` from
  fictional data.
- No fonts, icons, images or scripts from anywhere. The page uses the system
  font and a one-byte `data:` favicon.

## Dev dependency

`playwright` (Apache-2.0, Microsoft) is used only to run the browser tests. It
is not part of the viewer and nothing from it is shipped.
